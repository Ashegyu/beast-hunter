## 테스트 작성 시 주의 (0.103.2에서 정리한 내용)
- 고대 장비(0.110): 보스 고대 = 챕터 10스테이지 보스가 그 지역 번호의 고대(0.112부터 번호 = 지역: 1 숲지기, 2 서리, 3 폐성·망자; 0.119부터 4 바다·5 하늘·6 신역은 옛 카탈로그 파생이 아니라 `ancient-regions.js`에 직접 정의한 25종씩, `REGION_ANCIENT_BOSSES` 풀 abyss_tide/storm_sovereign/twilight_god, 특수효과는 ancient-powers.js의 4~6번째 배열(색 `REGION_COLORS`), 총 150종. 기본 카탈로그 티어 2가 폐성, 3이 서리라 `ancientIdOfBase`/`ANCIENT_TIER_OF_BASE`가 2↔3을 바꿔 고대 아이디·티어를 만든다. 고대는 계열의 기본 원화 아이디를 그대로 써서 원화 티어 ≠ 고대 티어일 수 있으므로 `equipmentArt`·`cleanItem`·`equipmentSnapshot`이 고대는 티어 비교를 건너뛴다. 저장 v15가 v14 이하의 고대 2·3번을 한 번 바꿔 옮긴다) 고대를 `ANCIENT_BOSS_CHANCE`(0.113: 일반 1%·정예 2%·악몽 3%, 사용자 요청 '진짜 잘 안 나와야')로 떨어뜨린다(`dropBossAncient`). 0.114부터 확정 드롭(천장) 없음(사용자 결정): 저장 필드 `legendaryPity`는 남아 있지만 쓰지 않는다. 레이드 고대는 0.123에서 추가(아래 레이드 항목). 테스트에서 고대 드롭을 확인할 때는 `s.lootRng` 시드를 바꿔 가며 고대가 나오는 처치를 찾는다(tests/ancient-items.test.mjs).
- 옵션 굴림(0.120): `PERFECT_ROLL_CHANCE`=.01이고 극옵은 그 추첨으로만 나온다(`rollWithin`: 극옵이 아니면 [min, max-1]). 범위는 기본 ±30%·추가 ±40%·고대/제작 ±20%, 상한 미달 옵션은 최소 두 값. 장비당 상한 `AFFIX_CAPS` 공격력 150·체력 500·그 외 25(`affixCap`, cleanItem·강화 보너스 상한도 같은 함수). 테스트에서 최댓값을 얻으려면 첫 난수를 0(극옵 추첨)으로 준다(.999는 max-1). 복원은 옵션·재설정 후보를 현재 범위로 맞춘다(후보를 버리지 않음).
- 무기 설계(0.120): 세트 `SET_STYLES.*.weapon`과 기존 `patterns.weapon`은 같은 예산(공격력 1·치명 .75·이속 .5·체력 .15 환산 약 11~12.5, tests/loot075 예산 테스트). 무기 고유 효과 중 storm은 1·2연격, frostNova는 3연격 마무리에 발동(0.104 파쇄 제거 뒤 죽어 있던 것을 0.120에서 복구). 수치 비교는 scratchpad의 wreal.mjs(실제 웨이브 60초 피해량, 시드 16~24개; 시드 8개는 잡음이 커서 결론 금지).
- 장비 확정 지급 없음(0.115, 사용자 결정. 강화 구간 보장, 대장간 제작 확정 성공(재료가 매우 드물어서), 던전 완주 재료 보상은 그대로 두기로 사용자 결정): `DROP_CHANCE`(일반 몬스터 .16, 정예 .7, 스테이지 클리어 보상 .7, 보스 장비 3개 각 .75)로 매번 `lootRandom` 판정, 일반 몬스터 10마리 천장(`lootPity`) 제거(필드는 남음). 판 단위 덮어쓰기 `s.lootRates`(저장 안 함): **장비가 꼭 나와야 하는 테스트는 `s.lootRates={normal:1,elite:1,stage:1,boss:1}`을 둔다**(launch 뒤, UI 테스트는 start 뒤 `ui.state`). 보스 결과를 단언할 때는 고대가 섞일 수 있어 `s.run.bossAncients.length`만큼 더해 센다.
- 난이도 장비(0.113): 장비의 `hunt`(1 정예, 2 악몽)가 기본 능력치 배율 `HUNT_POWER`(1/1.25/1.6)를 정한다(`affixRange`의 4번째 인자, `itemRollRanges`·승급·재련 모두 반영, `cleanItem`이 보존). 스테이지 드롭은 `rollStageItem({hunt})`가 `HUNT_GRADE_TABLES`로 등급을 정한다(일반 100 / 정예 55·35·10 / 악몽 20·40·30·10, **신화는 드롭 금지**(사용자 결정), 일반 난이도는 추가 난수를 쓰지 않음). 던전은 hunt 0. 보스 고대도 hunt 배율을 받는다. 고대 카탈로그는 150종(모두 개별 원화, 아틀라스 `ancient-individual-v0119` 150프레임, `numbering:'region'`; 0.120부터 공격력 상한 150이라 6티어 무기 83도 그대로), 능력치는 부위별 3종(`ANCIENT_STATS`)×(.76+.24×티어)×2.9.
- 고대 특수효과 차등(0.121): `ANCIENT_POWER_BY_ID`는 배율 1 원본이고 카탈로그 `signature`는 티어 배율 `ANCIENT_TIER_POWER`(1~1.5)를 damage/heal/shield/fury/haste에만 곱한 것(loot.js `scalePower`). 실제 전투는 `ancientSignatures(item)`(목록)을 쓴다: 정예 ×1.15, 악몽 ×1.3 + `NIGHTMARE_POWERS[계열]`(weapon/armor/charm, id `<고대>-nightmare`, 재사용 키 `ancient:<id>`). `uniqueLoadout` spec의 `signatures`, 투사체 `ancientSig`, 지대 `sig`로 전달. 저장 형식은 그대로(`hunt` 필드 사용).
- 고대 특수효과(`ancient-powers.js`): 150종 모두 고유(테스트가 수치 조합 중복을 막는다). 발동 조건 normal/finisher/skill/crit/kill/dash/perfect/hurt/lowHp/periodic/pickup(heavy·counter·idle은 자동 전투에서 발동하지 않아 0.110에서 없앰). 새 효과 fury/haste(시간제 버프, `s.uniqueState.ancientBuffs`, `ancientBuff(s,key)`가 damageEnemy·기본 공격 속도에 반영), invuln, cdr(스킬 재사용 감소), execute(비보스 처형). - 장신구(0.122): 스테이지는 무기·방어구만(`STAGE_SLOTS`). 목걸이·귀걸이·인장은 성장 던전 완료 때 `DROP_CHANCE.dungeon`(.4, `s.lootRates.dungeon`으로 덮어씀) 확률로 `rollAccessory`(부위 45/45/10, 티어 = `profile.unlockedStage` 챕터의 지역, 던전 4단계+ 정예 표·7단계+ 악몽 표, hunt 0)가 만들고 `s.run.dungeonReward.item`에 남긴다. 4~6지역 장신구는 `loot.js` `ACCESSORY_CATALOG`(24종, 고대 파생 대상 아님 — 옛 고대 이전 테스트는 `r.tier<=3`로 거름). 원화는 `chapters.js` `ACCESSORY_ART`(`acc_t<n>_charm|earring|seal`, 1~3지역 목걸이는 옛 부적 원화 유지), 프레임은 `manifest.equipment.setFrames`(페이지 `equipment-accessories-v0122`, setFrames 수 = 챕터×6+15). app.js 아이콘은 setFrames에 원화가 있으면 공용 부위 아이콘(`equipment-parts-v0970`) 대신 그것을 쓴다. cleanItem이 옛 귀걸이·인장의 `<forest|ruins|frost>_charm`을 새 원화로 옮긴다(제작 장비 제외).

- 악몽 콘텐츠(0.142, `tests/nightmare.test.mjs`): 악몽 열린 프로필은 `openMode(g,p,2,N+1)`(N장까지 악몽 처치, 0이면 악몽만 열림). 승화 장비는 `rollAncient` 후 `g.forgeAncient`로 만든다. 균열 클리어는 탑과 같은 방식(`s.run.wave=riftPlan(d,week).waves.length`, 퀘터 0, `stageKills=stageQuota` 후 한 틱) — 비내구 게임은 settlement 없이 바로 victory. 보스 드롭은 beast-techniques의 `killBoss` 패턴(`p.difficultyProgress`를 채워야 정예·악몽 10스테이지 launch가 된다). 균열 골드는 1e8 상한이라 고정 골드를 1e6으로. 레이드 테스트는 `RAIDS.filter(r=>!r.nightmare)`로 기존 3종만 돈다(악몽의 군주는 기본 프로필에서 잠김). 장비 기술 20종은 [template,element,execute,hits]가 모두 달라야 한다.
- 획득 경로 검증(0.149.11): 세트·보상 효과 테스트에서 장비를 `wear({slot:...})`처럼 카탈로그로 직접 만들면 실제로 안 나오는 부위도 끼워져 문제를 놓친다. 실제 보상 함수(rollAncient 등)를 여러 pick으로 돌려 나온 장비만 쓴다. CI(Pages workflow)는 sparse checkout(dist·tests·tools·art/monsters045·monsters065·skills053)이라 새 테스트가 다른 art 폴더를 읽으면 workflow에도 더할 것.
