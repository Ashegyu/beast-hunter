# 메인 기준 공통 메뉴 아이콘 · Alpha 0.96.1

가방·장비·스킬·제작·성장·도감·사냥터는 메인 화면의 동일한 원본 이미지와 data-lobby-icon 매핑을 사용합니다. 재료 추적은 메인의 미션 문양을 사용합니다. 메인에 대응하는 바로가기가 없는 홈·더보기는 공통 금색 SVG를 모든 창에서 사용합니다.

개별 PNG는 메인 원본의 정확한 64×64 구간을 잘라낸 리소스입니다. 원본 배경색을 보존하며 실제 UI에서는 screen 블렌드로 어두운 배경을 연결합니다. 알림 표시가 들어오던 모서리는 공통 CSS의 clip-path로 제외합니다. PNG 전체가 투명하다는 의미는 아닙니다. 홈·더보기 SVG는 투명 배경입니다.

atlas.png와 layout.json에 개별 위치·크기·배치 정보가 있습니다. 실제 구현은 menu-icons.css와 기존 home-scene.css의 공통 lobby-icon 정의를 함께 사용합니다. 기본 메뉴 28px, 낮은 가로 화면 24px, 장비 좌측 23~35px, 더보기 항목 32px이며 실제 메뉴 크기는 유지합니다. 선택 상태는 기존 배경·테두리와 아이콘 밝기 1.12로 표시합니다. 이미지가 클릭을 가로채지 않으며 버튼 이름·이동·초점·저장 동작은 그대로입니다.
