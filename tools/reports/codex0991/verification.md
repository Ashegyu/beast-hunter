# 도감 UI · Alpha 0.99.1

- 첨부 이미지 기준: 왼쪽 발견 기록/최근 발견, 오른쪽 검색/필터/카테고리/정렬/유물 목록, 하단 사냥터 이동.
- 기존 장비 이미지·75개 카탈로그·발견 상태·저장 형식 유지. 미발견 이미지도 원래 색상으로 표시, 발견 여부 문구 유지.
- 정렬은 필터 안에서 목록 상단으로 이동. 검색·카테고리·필터·이름순/발견 우선·격자/목록·상세/복귀 기존 동작 유지.
- 관련 UI 통합 검사 5개 통과. 브라우저 검색/정렬/보기 방식 전환 확인.
- 가로 667×375, 740×360, 844×390, 932×430 캡처. 브라우저 전체 폭 넘침 없음. 좁은 화면 5열, 표준 이상 6열; 목록 내부 세로 스크롤.
- 캡처의 발견 1개·재화는 Work 검증용 세이브이며 실제 플레이어 기록을 변경하지 않음.
- 신규 그림 없이 기존 배경·프레임·버튼 텍스처를 재사용. resources.json에 파일 경로와 배치 정보 포함.
