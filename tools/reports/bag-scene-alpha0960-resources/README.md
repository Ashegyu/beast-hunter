# 가방 화면 UI 리소스 · Alpha 0.96.0

기존 게임의 금속 프레임·버튼·배경을 재사용한 리소스입니다. PNG는 비율을 유지해 축소한 내보내기용이며 원본 WebP도 함께 제공합니다. 이미지의 투명도는 그대로 보존했습니다. `atlas.png`의 각 이미지 위치·크기와 화면별 슬롯 수는 `layout.json`을 참고하세요.

실제 구현은 `implementation/bag-scene.css`에 있습니다. 본문을 왼쪽 목록과 오른쪽 상세 정보로 나누고 우측에 6개 메뉴를 배치합니다. 아이템 선택 전후에 목록 폭을 유지합니다. 정렬·필터·일괄 정리는 목록 하단, 페이지 이동은 오른쪽 하단에 고정합니다. 상세 하단은 강화·분해·착용이며, 별 아이콘은 기존 즐겨찾기 보호 기능입니다.

모든 등급은 같은 슬롯 프레임을 사용하며 등급 색상은 아이템 뒤의 후광으로 표현합니다. 아이템 아틀라스·원화·장비 능력치·강화 규칙·저장 형식은 바꾸지 않았습니다. 효과 설명은 기존 설명 페이지 이동으로 전부 읽을 수 있습니다. 강화 작업은 넓은 화면으로 열리며 돌아오면 같은 장비의 상세 정보와 강화 버튼 포커스를 복원합니다. 일괄 분해 검토는 오른쪽에 표시하고 긴 대상 목록만 스크롤합니다.

패널 프레임은 원본의 18%를 기준으로 9-slice, 버튼은 중앙 50%/43%에서 400%×200% 확대 배경과 같은 프레임을 사용합니다. 개별 SVG는 기존 메뉴·카테고리의 원본 벡터입니다. 신규 아이템 이미지는 포함하지 않습니다.
