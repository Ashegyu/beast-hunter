# Alpha 0.56 — 글꼴과 텍스트 영역

사용자 선택지 중 글꼴 교체를 적용했다. 제목·지역명·주요 출발 버튼은 고운바탕 Bold, 버튼·본문·실시간 숫자와 Canvas 전투 문구는 IBM Plex Sans KR Regular/SemiBold다. 이전에는 대부분의 DOM이 같은 Pretendard 강제 규칙을 사용했다. 동일한 Hunter UI 별칭을 유지해 Canvas와 DOM이 새 글꼴을 함께 사용하며, 제목에만 Hunter Title을 지정한다. 피해 숫자는 실제 제공 굵기 600으로 그린다.

폰트는 Google Fonts 원본을 WOFF2로 무손실 포맷 변환하여 사이트 안에 포함했다. 런타임 외부 CDN 요청은 없다. OFL 원문과 원본 URL·배포 해시는 함께 보관했다. 세 파일 총 약 1.65MB이며 본문/제목을 preload하고 font-display:swap으로 글꼴 실패 때도 조작과 설명은 계속 표시한다. 원래 글꼴 파일은 이전 검토 자료/도구의 재현성을 위해 보존했다.

- 제목과 버튼, 설명, 수치의 역할을 구분한다.
- 스킬 이름은 10→12px, 대기 시간은 9→11px, 상세 설명은 12→13px.
- 인게임 스킬 버튼 폭을 202→246px로 확장하고 360px 이하에서는 228px. 각 이름에 두 줄 높이를 확보하며 버튼은 내용에 따라 자란다.
- 작은 화면의 스킬 목록은 3열로 표시한다. 설명과 표·장비명은 줄바꿈하고 컨테이너의 최소 폭을 0으로 둔다.
- typography.css를 skills.css 뒤에 적용해 글자 관련 규칙 우선순위를 명확히 한다.

검증: 모든 현대 한글 11,172자와 숫자/주요 구두점의 실제 폰트 cmap을 확인했다(glyph-coverage.json). 35개 스킬 이름 × 320/360/390px의 105개 경우를 실제 글꼴의 Canvas 글자 폭으로 측정했다. typography-review.png는 글꼴·크기 비교용 오프라인 조판이며 실제 브라우저/CSS 레이아웃이나 기기 화면 검증은 아니다. 실제 브라우저의 전체 화면 넘침과 모바일 성능은 미확인이다. 기존 전투/저장/메뉴 회귀 테스트를 함께 수행했다.
