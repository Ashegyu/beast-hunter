# Alpha 0.69 verification

## Changes and invariants

Three native transparent bitmap sheets provide 4 attack families × 4 stages × 3 regions = 48 frames. Region-specific shader-free bitmap stamps are connected to real monster volley casts, flight/impacts, melee contacts and committed charges. Event/projectile metadata records the chapter; live charge art uses the already committed charge vector. Visuals consume no RNG and cannot mutate simulation state or award damage/rewards. The existing hazard outlines and collision logic remain authoritative. Reflected shots switch to the existing friendly presentation. New charge/flight sprites stop at terminal hunt states.

One monster atlas is owned by the current region's existing image map. A new region validates its complete image set, metadata and frame/pivot bounds before promotion. Missing/invalid files cannot partially promote or overwrite progression; retry follows the same region loader. A stale completion cannot replace a newer selection, and previous-region images are removed from the map when a new region commits. Browser decoder/cache/GPU lifetime beyond these JavaScript references was not measured.

The new renderer uses one image stamp per visible projectile/charge/contact, no temporary canvas, no new Image objects, no wall clock and no per-frame numeric validation collections. Projectile simulation remains capped at 64 and alive enemies at 18; existing camera culling applies. Transfer assets add 4,399,430 bytes in total; the selected region adds one 1.46–1.47MB WebP and one 6,290,064-byte decoded RGBA surface (~6MiB). Startup resident image count is 20→21. These are asset/buffer sizes, not measurements of device GPU memory or FPS.

## Direction bugs

- Original crescent pixels have their leading arc on the left, while the renderer assumes local +X forward. A per-cell X mirror now corrects the bitmap after placement/rotation, preserving the forward anchor and hit corridor. Every ultimate using that source stamp receives the same correction.
- Seeking bitmap position followed a selected target, but its rotation still followed the original aim. It now derives heading from the actual from/target segment, including live target movement; a zero-length segment falls back to a finite aim.
- Returning blade's deliberate second-pass reversal is preserved, along with the original damage corridor. The fix does not globally mirror characters or swap world offsets.

## Evidence

Automated tests cover all eight character/projectile directions, local crescent correction without backward placement, seeking with deliberately opposite aim, outbound/inbound returning art, frame progression, purity and canvas restoration, alpha/bounds and malformed metadata, region promotion/eviction/retry, real monster cast timing, pause, friendly reflection and terminal state ownership. Real app VM tests verify generated bitmaps at contact in all three regions, stable paused frames, missing-file entry prevention and release on defeat. Existing regression tests cover combat, skills, saves and stage progression.

`npm test`: 552 tests passed, zero failures/skips, 73.34 seconds. The exact terminal log is retained in `tests.txt`. Additional syntax and whitespace checks are run before packaging.

`character-direction-review.png` compares previous/current production effect functions using the retained native player atlas in eight directions. `monster-effects-review.png` uses the production monster factory, projectile metadata and render functions with native creature art. Both were generated by `tools/render-effects069.mjs` and visually inspected offline. The old comparison baseline is source commit d3e239dbc5cc6f21d8f82f9cb27b793bc79665d1.

## Limits

Managed cloud browser control was unavailable. No preview server, browser install, alternate browser-control path, user computer or login was used. There is no claim of live browser, phone, touch or GPU/FPS validation. Generated animation has four discrete stages and some fine particles touch tile boundaries; the measured rectangles prevent sampling adjacent cells. Raw prompts, exact pixel equality checks and retained originals are under art/monster-effects069.
