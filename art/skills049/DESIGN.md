## 피해와 자원 계약

- 피해100%는 시전 시작 시 공격력1배. 새 스킬의 다단 피해표는 모든 타격을 합친 값이며, 각 타격에서 반올림과 적 방어가 따로 적용된다. 기존 공격력 성장·장비 공격력은 적용하지만 새 스킬은 기본 연격의 치명타·무기 상태이상·장비 고유 발동을 복제하지 않는다. 기존 연격과 파쇄는 해당 연계를 유지한다.
- 준비 동작이 있는 기술도 시전 시작에 기력과 대기 시간을 소비한다. 회피·피격으로 발도·윤무·연월참·적월난무·일섬을 취소하면 미발동 타격이 사라지고 비용은 환불하지 않는다. 이미 발사한 검기·영역·잔상은 유지된다.
- 연월참 피해 분배는25% /25% /50%. 잔영참은80+100%에서 시작해 단계마다10+15% 증가. 적월난무는60%×6+160%에서 시작해 단계마다10%×6+20% 증가.
- 낙월·파갑·발도·반격의 경직 누적이 크다. 일반 괴수의 기존 방어 게이지와 별도로 스킬 경직 누적100에서1.5초 노출과 경직 동작(1.1초)이 발생한다. 노출 피해 배율은 기존 엔진의1.5배를 사용한다.
- 파갑 약화·고독·무너진 균형의 추가 스킬 피해는 서로 합산한다. 장비·남겨둔 여력·수월 자세의 받는 피해 감소도 합산하고70% 상한을 적용한다.
- 기본 연격·파쇄는 한 동작 명중당 궁극기+1. 일반 피해 스킬은 한 시전 명중당+3이며 다수 적·다단으로 늘지 않는다. 완벽 회피·흘려베기 성공+8. 흘려베기의 피해 명중+3은 별도로 적용된다. 궁극기 자체는 게이지를 회수하지 않는다.
- 궁극기는 전투가 있는 동안 게이지100을 소비하며 기력을 사용하지 않는다. 월영군무는8초/8회 중 먼저 끝난 조건에서 종료된다. 새 사냥 시작 시 게이지0.
- 표식·검흔은 적 개체에 귀속되고 새 적에게 이전되지 않는다. 추가 피해는 표식 적중을 재귀 발동하지 않는다. 월영 공명으로 허용한 잔상 타격만 표식 횟수에 기여한다.
- 일시 정지는 대기 시간·지연 타격·버프를 모두 정지한다. 스테이지 종료 시 미발동 타격과 버프는 취소하지만 일반 스킬 대기 시간은 유지한다. 새 사냥은 전투 상태를 새로 만든다.

## 자동 사냥과 저장

균형은 기존 표적 선택, 보스 성향은 정예·보스 우선, 광역 성향은 밀집한 괴수 우선, 안전 성향은 일반 스킬 사용 후에도 기력35를 남긴다(그 외22). 월쇄는 근처3명 이상, 표식은 근처 정예·보스가 있을 때, 흘려베기는 예고 끝0.24초 이내에 시도한다. 발도·일섬은 근처 예고 중 적이 있으면 보류한다. 위험 회피가 일반 공격 스킬보다 우선이다. 궁극기는 정예·보스 전용/모든 적/수동 중 선택한다.

빌드3개는 장착 구성과 자동 성향·궁극기 정책을 함께 저장한다. 강화 투자는 캐릭터 전체에서 공유한다. 모든 변경은 거점에서만 가능하다. 저장은 기존7버전 형식에 skillBook을 추가하며 기존 골드·장비·숙련·진행은 보존한다. 잠긴 기술·중복 장착·잘못된 종류·초과 포인트는 복원 시 정리한다.

기존 Space/Shift/Q는 연격/회피/파쇄. E/R/T는 장착 일반1/일반2/궁극기. 이미지35종은 버튼·카드 아이콘이며 전투 판정은 이미지가 아닌 엔진이 소유한다. 전투 검기·원형·범위·표식은 Canvas로 별도 표현한다. 생성 이미지 프롬프트·해시는 assets.json, 이미지 검수는 QA.md 참조.

## 검증 범위

DOM/Canvas 호스트 통합 검증과 순수 전투 엔진 검증을 수행한다. 브라우저 제어 도구가 없어 실제 폰트/픽셀 배치·Android 터치·GPU·프레임 성능은 미검증이다. 로그인과 접근 정책 변경은 하지 않았다. tools/reports/skills049-simulation.json은 같은 조건의 단일 시뮬레이션4개로, 밸런스의 통계적 보증이 아니다.
