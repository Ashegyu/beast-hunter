# Alpha 0.62 — 성장·보상 흐름 점검

## 재현한 결함

1. **패배 정산 중 체력 회복**: 치명타 처리에서 collectGear가 먼저 실행되고 phase가 뒤늦게 defeat로 바뀌었다. 자석 장신구를 착용한 상태로 예약 전리품이 있으면 회수 효과가 HP를 0에서 5로 올린 뒤 패배 화면으로 갔다. 터미널 상태를 먼저 확정하고 전리품을 정산하도록 순서를 바꿨다. 보관과 중복 방지는 유지하며 패배 이후 전투 효과가 발동하지 않는다.
2. **숙련 포인트 환전 합계 누락**: 기존 숙련 강화 6종을 모두 채운 뒤 얻는 포인트는 35골드로 바뀌지만 run.gold에는 포함되지 않았다. 사냥 중 환전 금액을 결과 골드에도 합산하고 trainingGold로 내역을 표시한다. 실제 지급 금액은 기존과 같다.
3. **보스 보상 안내 불일치**: UI가 일반 스테이지 공식을 다시 계산했다. 예를 들어 빙하 악몽은 440골드·핵 5개를 지급하면서 51골드·핵 1개·체력 회복으로 표시했다. 실제 지급 지점이 일시적인 stageReward 내역을 만들고, UI는 그 값을 표시한다. 일반 스테이지의 체력 회복도 실제 회복량이 있을 때만 안내한다. 가방 자동 분해 내역은 별도로 함께 표시한다.

세 결함 모두 변경 전 실패를 확인한 뒤 수정했다. 패배 회수 테스트는 변경 전 HP 5, 환전 테스트는 결과 4골드/실지급 39골드, 보스 UI 테스트는 위의 51/1 표시로 실패했다.

## 성장 안내

- 사냥 결과에 획득 경험치, 시작→현재 레벨, 남은 스킬 강화/숙련 포인트, 새로 열린 스킬·슬롯·각성을 표시한다.
- 결과에서 스킬 정비로 바로 이동한다. 새 궁극기가 열렸으면 해당 설명을 선택하지만 자동 장착이나 자동 강화를 수행하지 않는다.
- 성장/스킬 화면에 가장 가까운 다음 해금 레벨과 이름을 표시한다. 슬롯 해금은 같은 데이터로 계산한다.
- Lv.50에서 경험치 바를 채워 최고 레벨임을 표시한다. 기존 경험치 상한 처리는 유지한다.
- 긴 해금 목록은 3개와 나머지 개수로 요약하고 전체 이름은 title에 보존한다. 새 텍스트 블록은 자체 줄바꿈과 최소 너비 0을 사용한다.

## 상태·저장·비용

새 값은 사냥 런타임의 startLevel/trainingGold 및 일시적인 효과의 지급 내역이다. 프로필 버전 7과 저장 형식, 장비 identity, 지급 확률, 전투 수치, 스킬 수치와 궁극기 60초 재사용 시간은 유지한다. 기존 장착 구성은 변하지 않는다.

성장 목록 계산은 성장/스킬 화면 또는 결과 화면에서만 수행하며 레벨·예산 키가 같으면 재사용한다. 사냥 중 프레임마다 목록을 만들지 않는다. 별도 타이머·비동기 작업·자원 소유자는 추가하지 않았다.

## 검증

- 보스 지급 내역 3챕터×3난이도 전체 9개 조합과 중복 지급 방지.
- 패배 시 전리품 보존, HP 0 유지, 이후 정지된 프로필과 재입장/재로드 보존.
- 사냥 중 숙련 포인트 환전의 한 번 지급과 표시 합계 일치.
- Lv.1~50 슬롯 규칙 보존, 구간 해금, 궁극기 및 최종 각성 경계.
- 실제 app.js 호스트에서 악몽 보스 보상, Lv.19→20 해금과 결과→정비→장착→재로드, Lv.49→50 경험치 상한과 안내 확인.
- 최종 npm test 전체 506개 통과, 실패 0개(약 42.4초). 실행 출력은 test-results.txt에 보관한다.

`node tools/review-growth062.mjs`는 이전 엔진 커밋 84198d55와 현재 엔진을 같은 경로로 실행한다. 다른 엔진 의존 모듈은 현재 것을 공유하며 슬롯 규칙의 동등성은 별도 검사했다. 저장 프로필 전체와 측정한 사냥 집계가 동일했다. 한 결정적 자동사냥 경로의 챕터별 도달 레벨은 9/12/15, 경험치 921/1023/1125, 골드 680/1221/1572였다. 통계적인 난이도/빌드 밸런스 검증을 뜻하지 않는다.

`growth-text-review.png`는 실제 성장 안내 함수와 현지 글꼴을 사용한 288/358px 폭의 오프라인 텍스트 조판이다. 브라우저 CSS 레이아웃이나 전체 게임 화면의 스크린샷이 아니다.

## 남은 확인과 다음 후보

관리 환경에 control-browser가 없어 실제 브라우저·터치 기기의 카드 높이/스크롤/줄바꿈을 검수하지 못했다. 실제 기기 프레임 시간도 측정하지 않았다.

이번 결정적 경로에서는 3챕터 완료 시 Lv.15이고 첫 궁극기는 Lv.20이다. 신규 기능 이전의 다음 조정 후보는 첫 궁극기까지의 성장 속도와 반복 사냥의 목표다. 여러 빌드와 반복 경로를 측정한 뒤 경험치 곡선/해금 목표를 정하는 것이 필요하다.
