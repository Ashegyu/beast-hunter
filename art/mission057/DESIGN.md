# Alpha 0.57 — 미션 텍스트와 장식 프레임

확인된 기존 제약:

- portrait.css가 top-hud 폭을 200px로 고정한 뒤 일부 .mission은 210~230px 폭을 사용했다.
- combat-art.css의 mission은 max-height:56px/overflow:hidden, padding:7px 12px를 적용했다.
- 배경 이미지 combat-mission-v046.webp는 374×184이며 두꺼운 내부 장식이 있다. CSS 상자 안의 글자도 실제 그림 테두리 안쪽 영역과 겹칠 수 있었다.
- 보스 체력바와 알림은 각각 절대 top 오프셋으로 떨어져 있어 미션 텍스트 높이가 늘어나도 위치를 따라가지 않았다.

변경:

1. 미션/보스/알림/제작 추적기를 같은 top-hud의 Grid 흐름에 둔다. ID와 이벤트 연결은 유지하고 글자 높이 측정용 JS/ResizeObserver를 추가하지 않는다.
2. portrait HUD의 폭을 좌우 12px 여백 기준으로 통일하고, mission 폭은 부모 100%로 둔다. 추적기 표시가 미션을 임의 폭으로 좁히지 않는다.
3. 기존 프레임 이미지를 border-image 9분할로 사용한다. 모서리는 보존하고 내용 부분만 늘리며, 16px/20px 테두리와 안쪽 padding으로 텍스트 영역을 확보한다.
4. 미션은 챕터/웨이브, 단계/이름, 현재 목표의 세 행이다. 제목과 목표는 보통 흐름에서 줄바꿈하며 최대 높이·말줄임·nowrap을 제거한다. 작은 가로 화면은 챕터 영문만 숨기고 내용 높이는 유지한다.
5. 보스/알림은 더 이상 별도 절대 top에 의존하지 않고 앞 행 뒤에 배치한다. 숨긴 항목은 기존 hidden 규칙을 유지하며, HUD는 pointer-events:none이고 실제 버튼만 입력을 받는다.

검증: 485개 기존 테스트 통과. HTML ID 유일성과 보스/알림/추적기/미션의 공유 부모 확인. tools/review-mission-hud057.mjs로 4개 폭 × 5개 미션 × 3개 난이도 × 4개 진행 문구(240개)의 실제 글꼴 폭을 확인했다. mission-panel-review.png는 실제 글꼴과 프레임을 이용한 오프라인 조판이며 브라우저/CSS 화면 검증은 아니다. 브라우저/실기기 레이아웃은 미확인이다.
