# Alpha 0.54 — 시간 기반 궁극기

적월난무 / 일섬·월식 / 월영군무는 해금·장착 후 새 사냥 시작 시 사용 가능하며, 시전 순간부터 60초의 게임 시간 쿨다운을 적용한다. 명중·처치·완벽 방어 충전 게이지를 제거했다. 버튼과 상세 설명에는 초 단위를 표시하며 0초가 되기 전에는 준비로 표시하지 않는다.

일시정지·백그라운드에서는 게임 시간과 함께 멈춘다. 같은 사냥의 웨이브·방 전환에서는 남은 시간을 유지하고, 거점에서 새 사냥을 시작하면 초기화한다. 취소해도 재사용 시간은 환급하지 않는다. 사냥의 여세는 설명대로 일반 스킬만 단축한다. 자동 사냥의 궁극기 정책은 기존대로 유지하며 같은 쿨다운을 따른다. 피해·해금·강화·궁극기 영상은 기존 그대로다.

검증: 엔진의 3종 공통 경계·일시정지·취소·방 정리·새 사냥·자동 정책, 실제 앱 모듈의 버튼/상세 설명/영상 회귀를 headless 테스트로 확인한다. tools/reports/skills054-simulation.json은 네 빌드의 단일 고정 조건 보스 시뮬레이션이며 통계적 밸런스 또는 실제 브라우저 영상 검증은 아니다.
