# Alpha 0.142 스킬 이펙트 원화 (Codex CLI 생성, 스킬별 색 · 파편)

사용자 요청 '스킬 이펙트가 이질적, 더 화려하게, 색상 추가, 파편 느낌'. 0.137 원화 16종은 모두 분홍·빨강 한 가지 색에
깃털처럼 뭉개진 그림이라 게임의 선명한 그림체와 따로 놀았다. 같은 6프레임 연속 동작 구성으로 다시 그렸다.

1. 사양 `anim.json`의 `anim-<id>`(3×2 = 6프레임, 1536×1024). 첨부는 0.137 키 아트(`art/skills0137/keys/<id>.png`)를
   **모양·방향 참고만**으로 쓰고, 프롬프트에 스킬마다 새 팔레트(`palette` 필드)와 '선명한 셀 셰이딩, 각진 결정 파편,
   부드럽거나 깃털·꽃잎 같지 않게'를 넣었다. 단발 기술은 4프레임째에 파편이 터져 나가고 5·6프레임에 흩어진다.
   생성 `python3 tools/codex-monster-sheet.py art/skills0142/anim.json anim-<id> --attempts 4`(6개 병렬, 장당 약 1~2분).
2. 12종 + 파갑참·혈월의 칼날은 첫 시도 통과. 반복형 원 3종(잔월진·표식·수월의 자세)은 빛 번짐이 칸을 채워 자동 검사
   (완전 투명 30% 이상)에 걸렸지만 반투명 알파가 실제로 있고 테두리 알파가 0~16인 것을 확인하고 눈 검수로 채택했다
   (field try1, mark try2, stance try1 — `prompts/<id>.json`의 final은 비어 있다).
3. 포장 `python3 tools/pack-skills0142.py` → `dist/assets/skill-effects-v0142.webp`(2040×2040, 칸 204px, 0.137과 같은 배치),
   manifest `skillPresentation.effects`를 바꾸고 옛 `skill-effects-v0137.webp`는 지웠다(0.137 원본은 art/skills0137에 남음).
