# Alpha 0.61 — 품질 2단계: 전투 피드백

## 확인한 문제와 변경

- 공격 예고 외곽선은 이미 효과 뒤에 그려지고 있었다. 이 순서는 유지하고, 부채꼴 탄막 예고에도 짙은 바탕 선을 추가했다.
- 투사체는 스킬 효과보다 먼저 그려져 화려한 효과에 가려질 수 있었다. 타격 표시와 살아 있는 투사체를 효과 뒤에 그린다. 적 탄환은 따뜻한 호박색과 짙은 테두리, 아군 탄환은 기존 녹색으로 구분한다. 발사 높이 35px, 지면 좌표 및 투사체 충돌 판정은 기존대로다.
- 모든 스킬 시전이 heavySwing으로 매핑되어 있었다. 일반 액티브 16종과 궁극기 3종에 서로 다른 주파수/길이의 짧은 시전음을 적용했다. 표식 시전도 해당 소리를 전달한다. 명중음은 기존 실제 접촉 이벤트에서 발생한다.
- 일반 타격은 짧은 검흔, 강타는 고리와 긴 파편, 치명타는 금빛 파편, 방어는 푸른 각진 방어 반응으로 그린다. 공격 방향과 치명타 여부를 일시적인 impact 이벤트에만 추가했다.
- 오프라인 합성에서 적월난무의 다단히트 효과가 캐릭터 중심을 하얗게 덮는 것을 확인했다. 겹치는 밝은 검기를 바깥쪽 궤적으로 분산하고 중앙 고리의 세기를 낮췄다.
- 동작 줄이기 환경에서는 화면 흔들림을 끄고 타격 파편을 줄인다.

## 상태와 비용

새 렌더러는 상태를 읽기만 하며 이미지, 타이머, 난수, 게임 이벤트를 생성하지 않는다. 캔버스 상태는 finally로 반환한다. 가장 최근의 보이는 접촉 최대 10개를 표시한다. 시전음과 방어 접촉음은 각각 프레임당 최대 2건, 오디오 전체는 기존의 최대 10음성을 지킨다. 중단/음소거 시 예약된 음성도 해제하며, 일시정지 중 소비한 이벤트를 재개할 때 재생하지 않는다.

장비/저장 형식/진행도/스킬 수치/공격 판정/쿨다운/무적/히트스톱은 변경하지 않았다. 작은 아이콘 전투 버튼과 60초 궁극기 쿨다운, 제거된 궁극기 영상 정책도 유지한다.

## 검증

- 실제 app.js를 실행하는 호스트에서 효과 아틀라스 → 접촉 표시 → 투사체 → 공격 예고의 순서를 검사했다. 정지된 프레임을 다시 그려도 전투 상태가 변하지 않음을 확인했다.
- 스킬 ID 전달, 표식 시전, 한 번만 재생, 일시정지 후 재생 방지 및 다수 방어 접촉음 제한을 검사했다.
- Web Audio 테스트 대역에서 19종의 음색 매개변수 서명이 서로 다름과 음성 수 상한/예약 음성 해제를 검사했다. 실제 스피커로 들은 청음 검수는 수행하지 않았다.
- 순수 렌더러에서 일반/강타/치명/방어의 구별, 동작 줄이기, 수명 종료, 잘못된 속도 입력, 예외 발생 시 캔버스 상태 복구를 검사했다.
- 최종 npm test 전체 499개 통과, 실패 0개(약 47.7초). 전체 출력은 test-results.txt에 보관했다.

`combat-contact-before.png`는 이번 수정 중 적월난무 검기의 중앙 배치를 바꾸기 전이다. `combat-contact.png`는 수정 후 같은 장면이다. 실제 아틀라스와 프로덕션 효과 렌더러, app.js에서 읽은 공격 예고 함수를 사용한 오프라인 조합이며 브라우저 스크린샷이 아니다. `node tools/review-combat061.mjs`로 최종 조합을 재생성한다.

오프라인 N-API 캔버스에서 새 피드백만 10접촉+64탄환으로 200회 측정했다. p95 1.024ms, 최대 2.437ms였다. 전체 게임/브라우저/GPU/오디오/모바일 프레임 성능을 뜻하지 않는다. 원자료는 feedback-cpu.json이다.

Sites 관리 환경에 control-browser가 제공되지 않아 실제 브라우저·터치 기기 검수는 미완료다. 다음 단계는 성장/보상 흐름을 확인하고 기존 시스템의 수치를 점검하는 것이다.
