# Alpha 0.76 검증

요청 범위: 작은 획득 알림에서 장비 이미지 제거, 획득 순간 연출 강화, 실제 골드·재료 바닥 수집, 챕터 결과의 획득 장비 이미지.

## 동작과 수명

- 일반 몬스터 골드와 모든 드롭 재료는 소유 예약 후 바닥에 생성되며 수집할 때 지급한다. 동전은 Canvas 그래픽, 재료는 기존 이미지다. 새 원화나 초기 이미지 요청을 추가하지 않는다.
- 착지 0.35초, 일반 수집 620/초, 웨이브 종료 자동 회수 1050/초. 가까운 지점에서 이동 거리를 제한해 지나침을 방지한다. 바닥 재료에 만료 시간이 없다.
- 즉시 리젠과 다음 스테이지 진입을 막지 않는다. 남은 골드·재료만 새 스테이지로 넘기며 이전 공격과 장판은 넘기지 않는다.
- 예약 수량은 수집 때 차감하고 사망·시간 초과·귀환·재접속 때 한 번 정산한다. 시각 복제·일시정지·저장 왕복·보유 상한을 검사한다. 스테이지 완료·보스 완료·자동 분해 골드는 기존 직접 보상 경로다.
- 장비 획득 연출은 최대 한 개의 대형 연출과 세 개의 작은 연출, 자원 피드백은 최대 네 개다. 0.12초 안의 같은 자원 피드백은 수량만 합치고 수명을 연장하지 않는다. 소리는 프레임당 장비 한 개·골드 한 개·재료 한 개를 선택하고 기존 10 voice 제한을 따른다. reduced motion은 움직이는 입자와 빛기둥을 생략한다.
- 결과 장비는 실제 정산 기록을 등급순으로 정렬하고 고정 12카드만 렌더한다. 모든 페이지·빈 결과·가방 초과·자동 분해·재사용 ID와 상태 갱신을 검사한다. 장비 자체를 저장 프로필에 중복 추가하지 않으며 결과 참조는 새 사냥/귀환 때 해제한다.

## 검증과 재현

`npm test`: 585/585 통과. 전체 기록: ../../tools/reports/pickup076-tests.txt. 새 엔진 검사는 tests/pickup076.test.mjs, 실제 app.js DOM/Canvas 호스트 검사는 tests/game-ui.test.mjs, 효과음 검사는 tests/sound.test.mjs에 포함한다. 기존 보상 합계 검사는 지급된 골드와 예약된 골드를 합산해 중복 지급을 계속 검출한다.

`node --experimental-vm-modules tools/render-pickup076.mjs`는 실제 app.js와 원본 WebP를 native Canvas로 실행한다. pickup-scenes.png는 실제 전장 Canvas의 바닥 드롭·수집·극옵 파동이다. floor.png/collect.png/pulse.png는 전체 원본 화면이다. scenes.json은 각 캡처 순간 값의 복사본이며 지급 전 골드 0/예약16·뼈철0/예약2, 수집 후 골드16/예약0·뼈철2/예약0을 확인한다.

result-art-check.png는 실제 결과 DOM에 연결된 아틀라스 프레임을 native Canvas에 다시 그린 원화 확인용 접촉 시트다. 실제 CSS 결과 화면의 스크린샷이 아니다. 보스 fixture로 실제 보상과 결과 연결을 실행했으며 이 도구로 전체 캠페인 플레이를 주장하지 않는다.

JavaScript 구문, HTML 닫힘/ID, 파일 링크 및 git diff 공백을 검사한다. 관리형 control-browser 기능을 사용할 수 없어 브라우저 직접 검수는 생략했다. CSS 계산 배치·실제 터치·기기 GPU/메모리·음질/손맛은 이 자동 검사와 오프라인 렌더로 확인되지 않는다. 사용자 컴퓨터나 로그인을 사용하지 않았다.
