# Alpha 0.50 — 개별 스킬 모션과 전투 효과

기존 리리안 방향별 원화 프레임을 스킬별 시간표로 재구성하고, 같은 프레임의 장비 소켓에 무기를 부착한다. 새로 그린 19개 원화 애니메이션 시트가 아니라, 19개 고유 시전/공격/회수 동작과 Canvas 효과다. 피해 수치·횟수·쿨다운·해금 규칙은 0.49를 유지한다.

16개 패시브는 발동 시 서로 다른 룬을 표시하며 같은 룬의 반복 표시는 1.2초 간격으로 제한한다. 지속 버프·표식·파갑 표시는 실제 만료 시간에 연결한다. 분신은 최대 4개, 적 상태 장식은 최대 64개로 제한한다.

질풍참·잔영참·낙월은 순간 좌표 변경을 시전 시간에 따른 실제 이동으로 교체했다. 회피·피격·전투 종료 시 이동과 모션을 취소한다. 이동은 경기장 경계에서 멈추며 타격 작업과 접촉 프레임은 같은 게임 시간을 사용한다. 일시정지 동안 이동·모션·피해 작업은 정지한다.
