# Alpha 0.55 — 인게임 궁극기 연출

궁극기 영상과 전체 화면 컷인 호출을 앱에서 제거했다. 기존 일러스트를 대체 표시하는 fallback도 호출하지 않는다. 시작 시 전투 이펙트 아틀라스만 불러오고 궁극기 인물 그림 3장은 요청하지 않으며, video 요소/디코더를 만들지 않는다. 과거 원본과 순수 렌더링 API는 보존했다.

- 적월난무: 반경 260의 회전 검기, 겹친 붉은 궤적, 마지막 확산 충격파와 불꽃.
- 일섬·월식: 시전 지점/방향을 고정하고 0.65초 준비 후 길이 560의 관통 섬광, 교차 검흔과 끝단 입자.
- 월영군무: 캐릭터 주변 궤도 검기와 여섯 잔상, 보랏빛 입자. 기존 8초 잔상 공격/버프는 유지.

추가 연출은 기존 생성 이미지 아틀라스를 사용한다. 1.35초짜리 단일 런타임 표시 상태로 소유하며, 프레임마다 effect 목록이나 랜덤 입자를 생성하지 않는다. 렌더러는 시뮬레이션을 수정하지 않고 1회당 최대 16회 이미지 그리기로 제한한다. Canvas 상태는 save/finally/restore로 복구한다. 전체 화면을 덮는 레이어/번쩍임 없이 월드 좌표에 그린다. 일시정지는 게임 시간과 함께 멈추며, 취소·사망·거점/방 전환·토큰 변경·만료 시 숨긴다. 움직임 줄이기는 회전과 입자 이동을 억제한다.

피해, 판정, 캐릭터 모션, 해금/강화, 60초 쿨다운과 자동 사냥 정책은 유지했다.

검증은 실제 앱 모듈의 세 궁극기 버튼을 320/390/960px에서 실행하여 영상/컷인 미표시·미로딩, 입자 표시, 일시정지/취소 및 쿨다운을 확인한다. 순수 렌더러의 유한 좌표·그리기 횟수·상태 복구·불변성·연출 구분과 수명 경계도 검사한다. ultimate-field-contact.png는 tools/render-ultimate-field055.mjs로 실제 엔진/어셋을 그린 오프라인 렌더이며 브라우저 스크린샷은 아니다. 실제 브라우저/GPU/모바일 프레임 시간은 측정하지 않았다.
