# Alpha 0.77 검증

## 변경과 보존

실제 장비 보관 이벤트 lootPickup의 도형 불꽃을 생성한 투명 이미지로 교체했다. 4종×4프레임의 한 장을 공유하며 최초 로딩 21→22장, WebP 1,535,414 bytes/디코드 RGBA 6,290,064 bytes를 추가한다. 이미지를 프레임마다 로드·디코딩하거나 새 Canvas/배열을 만들지 않는다. 최대 네 연출×두 교차 전환 이미지로 한 프레임 8회 stamp 상한을 유지한다. 동작 줄이기는 150px 고정 프레임을 사용한다. 효과 수명은 기존 엔진 이벤트의 0.6/1.05초를 따른다. 보상·소유권·저장·난수·피해 엔진 파일은 수정하지 않았다.

몬스터 공격 준비 중 장판을 그리던 telegraphs 함수와 전·후 두 호출을 삭제했다. 일반/보스 강타의 채움·범위 테두리·진행 원·조준점이 없다. 실제 공격 준비 동작과 접촉/발사 후 이펙트·투사체·플레이어 스킬은 유지한다. 몬스터 등장 예고와 폭발핵 오브젝트는 이번 공격 장판 제거 대상과 별개다.

## 검증

npm test: 588/588 통과. 원시 기록: ../../tools/reports/fx077-tests.txt. 실제 app.js DOM/Canvas 호스트에서 등급 행·네 시점 선택·프레임 교차·정립 투영·수명 종료·일시정지·효과음 일회성·보상/난수 불변·20개 동시 이벤트 렌더 상한을 검사했다. 이미지 로딩 실패/치수 손상 시 전투 진입 차단, 보유 자원 보존과 정상 재시도도 확인했다. 기존 결과 장비/골드/재료의 저장 복구·중복 방지 및 캠페인 회귀를 포함한다.

일반/보스 강타의 장판·조준점 부재, 원거리/돌진 표시 부재, 실제 타격/궁극기/투사체의 렌더 순서와 고정 공격 상태 불변을 검사했다. HTML 닫힘·1466개 ID 유일성·23개 로컬 script/style 경로, JavaScript 구문과 git diff 공백도 검사했다.

node --experimental-vm-modules tools/render-pickup077.mjs: 실제 app.js와 디코딩한 원본 지역/캐릭터/몬스터/이펙트 이미지를 native Canvas로 실행한다. pickup-atlas-in-game.png는 4종×4시점 렌더이며 windup-without-area.png는 원형 공격을 준비하는 오크에게 장판이 없는 화면이다. scenes.json은 선택한 실제 source/destination 사각형과 시뮬레이션 불변 여부를 보존한다. 통제된 효과/준비 상태 fixture이며 전체 사냥 플레이를 의미하지 않는다.

control-browser 기능을 사용할 수 없어 관리형 브라우저 직접 검수는 생략했다. 이 이미지는 DOM/CSS 화면 캡처가 아닌 실제 전장 Canvas 오프라인 렌더다. 실기기 GPU 비용·FPS·메모리·터치·음질은 측정하지 않았다. 사용자 컴퓨터와 로그인을 사용하지 않았다.
